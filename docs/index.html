jp-geocoder

日本の住所を扱うための、サーバもDBもAPIキーも要らない JavaScript ライブラリです。このページ自体が実物で、 あなたのブラウザの中だけで動いています（サーバ側の処理はゼロ）。

  • 住所 → 緯度経度 表記ゆれ・タイポ・旧市町村名・カナ入力を吸収して解決します。
  • 都道府県 → 市区町村 フォームの選択肢に使える市区町村の一覧を返します。
  • 住所 → 最寄り駅 全国1万駅。座標を経由して、住所からそのまま最寄り駅を出せます。
  • どこまで解けたかを必ず返す 「たぶん合ってる座標」を黙って返しません。粒度と品質を明示します。
住所を入力してください。
