jp-geocoder

日本の住所・駅を扱う JavaScript ライブラリ。サーバも DB も API キーも 不要で、静的 JSON への fetch だけで動きます。このページ自体が実物です。

住所
駅・路線
出典: デジタル庁「アドレス・ベース・レジストリ」/ 国土交通省「位置参照情報」/ 『歴史的行政区域データセットβ版』（CODH作成）/ 駅データ.jp

geocode()

住所文字列を緯度経度に変換します。表記ゆれ・タイポ・旧市町村名・カナ入力を 吸収し、どこまで解決できたか（matchLevel）と座標の品質 （accuracy）を必ず返します。

geocode(address: string): Promise<GeocodeResult>
候補
住所を入力してください。
読み方
matchLevel — どこまで解決できたか rsdt 号（住居表示） block 番（街区） parcel 筆（地番） oaza 町字 city 市区町村 pref 都道府県 accuracy — その座標の品質 surveyed 実測点 legacy 公図由来。数十m ずれうる representative 代表点。目的地の点ではない

listMunicipalities()

都道府県に属する市区町村の一覧を返します。フォームの選択肢に使えます。

listMunicipalities(pref, options?): Promise<MunicipalitiesResult>

designatedCity は政令指定都市20市の見せ方だけを切り替えます。 wards は行政区ごとに1件（横浜市なら18件）、nested は市1件に区をまとめます。特別区・郡部の町村・通常の市はどちらも同じです。 郡名は含めません。

市区町村
都道府県を選んでください。

nearestStationsByAddress()

住所を座標に変換し、そのまま最寄り駅を返します。全国 10,465駅。 距離は直線距離[m]です。

nearestStationsByAddress(address, options?): Promise<…>
最寄り駅
住所を入力してください。

listLines() / listStations()

都道府県に乗り入れる路線を出し、選んだ路線の駅を路線順に返します。

listLines(pref) → listStations({ pref, line })

駅は路線上の並び順で返します（駅コード順ではありません）。分岐のある路線は 1本の列に並べられないため、分岐箇所だけ順序が飛びます。

駅
都道府県を選んでください。
